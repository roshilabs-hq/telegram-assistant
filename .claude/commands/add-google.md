---
description: מוסיף את התוספת "יומן Google ו-Gmail"
---

מוסיפים את התוספת "יומן Google ו-Gmail". ההוראות נמצאות ב-`addons/04-google.md`.
- **הכנה:** מסבירים את "למה" במשפט. זה השלב הכי ארוך, אז אומרים מראש שהוא לוקח כרבע שעה ושעוברים אותו פעם אחת.
- **ליווי:** מלווים את חלקים א׳ עד ג׳ צעד אחר צעד. חלק אחד בכל פעם, ומחכים שהמשתמש יגיד שסיים.
- **כתובת החזרה:** מוצגת בעמוד ההקמה עם כפתור העתקה. אפשר גם להרכיב אותה מ-`KIT_URL` שב-`.env.local` (`<KIT_URL>/api/google/callback`), מבלי להציג סודות.
- **המפתחות:**
  - מוסיפים ל-`.env.local` שורות ריקות `GOOGLE_CLIENT_ID=` ו-`GOOGLE_CLIENT_SECRET=` אם הן חסרות.
  - פותחים את הקובץ למשתמש, והוא מדביק בו את המפתחות.
  - בודקים קיום עם `npm run check`, בלי לקרוא את הקובץ.
- **אחרי Redeploy:** מובילים לכפתור החיבור בעמוד ההקמה, ומכינים את המשתמש מראש למסך "Google hasn't verified this app". זו האפליקציה שלו, ולוחצים Advanced.
- **בדיקה:** `npm run check` (השורה "יומן Google ו-Gmail"), ואז הודעה "מה יש לי מחר?" לבוט.

אותם חוקים כמו ב-`/start`: עברית פשוטה, לא קוראים את `.env.local`, ולא מבקשים מפתחות בצ'אט.
