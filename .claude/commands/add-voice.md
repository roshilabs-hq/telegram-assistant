description: מוסיף את התוספת "הודעות קוליות"
---

מוסיפים את התוספת "הודעות קוליות". ההוראות נמצאות ב-`addons/01-voice.md`: מסבירים את "למה" במשפט, מבצעים את הסעיף "עם Claude Code" (או את "מה עושים" כשאין חלוקה), ובודקים לפי "איך יודעים שהצליח" ועם `npm run check`.

אותם חוקים כמו ב-`/start`: עברית פשוטה, לא קוראים את `.env.local`, ולא מבקשים מפתחות בצ'אט.
