את/ה מקים/ה עכשיו עוזר אישי בטלגרם בשביל מישהו שעובד ב-Claude Code. ייתכן שהוא לא מכיר את GitHub, את Vercel או את BotFather.

**העיקרון:** כל מה שאפשר להריץ במחשב, את/ה מריץ/ה בעצמך: Git, GitHub CLI, Vercel CLI, יצירת קבצים, סיסמה ובדיקות. **באתרים המשתמש לוחץ בעצמו** (BotFather, ספק ה-AI, אישורים בדפדפן). אין טייס אוטומטי באתרים, ולא פותחים דפדפן בשבילו. בכל פעולה שלו אומרים בדיוק על מה ללחוץ, במשפט או שניים.

## שאלה אחת בהתחלה
ב-AskUserQuestion: **"כמה הסבר אתה רוצה בדרך?"**
- **הסבר קצר לכל שלב (מומלץ)**: משפט "למה" לכל שלב, ולכל מונח חדש (ראו `docs/glossary.md`).
- **רק מה לעשות**: בלי הסברים, אלא אם שואלים או שמשהו נתקע. הבדיקות לא מתקצרות.

## 0. הקוד
אם התיקייה הנוכחית היא כבר הערכה (`package.json` עם `"name": "telegram-assistant"`), מדלגים לשלב 1.

אחרת (המשתמש הדביק את השורה בתיקייה אחרת): `git clone https://github.com/roshilabs-hq/telegram-assistant telegram-assistant`. אם התיקייה קיימת, בוחרים `telegram-assistant-2` וכן הלאה. מכאן כל פקודה רצה בתוך התיקייה החדשה. העותק הזה זמני: בשלב 3 הוא עובר לחשבון של המשתמש.

## 1. מה מותקן
`node scripts/setup.mjs preflight`. אם Node ישן מגרסה 20, מבקשים להתקין את גרסת ה-LTS מ-https://nodejs.org ולפתוח מחדש את VS Code.

## 2. קובץ אחד לכל הסודות
`node scripts/setup.mjs env`, ואז `code .env.local`. בקובץ יש שדות, ולכל אחד הסבר וקישור. המשתמש ממלא אותם, לפי הסדר:
1. **`GITHUB_TOKEN` ו-`VERCEL_TOKEN`:** הם קובעים **באיזה חשבון** הכול נוצר. נכנסים לקישור שבקובץ, יוצרים טוקן עם תפוגה של 30 יום, ומדביקים. אין לו חשבון Vercel? נרשמים ב-https://vercel.com/signup עם GitHub, ורק אז יוצרים טוקן.
2. **`TELEGRAM_TOKEN`:** לפי "בקצרה" ב-`steps/01-create-bot.md`.
3. **`AI_API_KEY`:** קודם שואלים ב-AskUserQuestion איזה ספק, ו-Gemini ראשון עם "(מומלץ)". את העלות של כל ספק לוקחים מהטבלה ב-`steps/02-ai-key.md`, ולא כותבים מספרים מהזיכרון. אחר כך עובדים לפי `steps/02-ai-key.md`, כולל חיבור אמצעי תשלום ו**תקרת הוצאה**. את פרטי הכרטיס המשתמש מזין בעצמו באתר של הספק.

אפשר למלא הכול בבת אחת. כשהוא אומר ששמר: `node scripts/setup.mjs verify` ו-`node scripts/setup.mjs accounts`. על כל ❌ עונים לפי ההודעה, ומריצים שוב.

## 3. אישור החשבונות, והעותק הפרטי
1. מראים למשתמש את השמות ש-`accounts` הדפיס, ושואלים ב-AskUserQuestion: **"ליצור את העותק ב-GitHub של X ולהעלות ל-Vercel של Y?"** האפשרויות: "כן" ו"לא, תחליף טוקן". **בלי "כן" לא ממשיכים.**
2. `node scripts/setup.mjs repo`. הפקודה יוצרת עותק פרטי מהתבנית בחשבון של הטוקן, ומעבירה את התיקייה אליו.
3. **לפני כל commit** (רק כשמשנים את הבוט אחרי ההקמה): בודקים `git config user.email`. אם ריק, מבקשים את המייל שאיתו נרשם ל-GitHub, ומגדירים אותו (Vercel בתוכנית החינמית חוסם קומיט של מחבר אחר).

**המשתמש לא רוצה ליצור טוקנים?** עובדים עם החשבונות שמחוברים במחשב, אבל רק אחרי אישור:
- **GitHub:** מראים את `gh auth status` ושואלים באיזה חשבון. אחרי שהוא אישר: `gh repo create <שם> --template roshilabs-hq/telegram-assistant --private`, ומעבירים את `origin` אליו.
- **Vercel:** מראים את השם מ-`preflight` ושואלים. לחשבון אחר: `node scripts/setup.mjs login`. **לא מריצים `vercel login` ישירות**, כי בלי הסקריפט הוא קורס כששם המחשב בעברית.

## 4. העלאה לאוויר
`node scripts/setup.mjs deploy`. הפקודה יוצרת פרויקט ב-Vercel, מחברת אותו ל-GitHub (בשביל העדכונים), מחברת Supabase בפרנקפורט, מעבירה את שלושת הסודות ומעלה.
- **אם Supabase מבקש אישור** ונפתח דפדפן: המשתמש מאשר שם, ומריצים את `deploy` שוב. הפקודה ממשיכה מאיפה שעצרה.
- בסוף הכתובת של הבוט נכתבת לבד ל-`.env.local` (`KIT_URL`).

## 5. הפעלה וחיבור
1. `node scripts/setup.mjs activate`. הפקודה יוצרת את הטבלאות, מחברת את הבוט לטלגרם ומפעילה את התזכורות. בסוף היא מדפיסה קישור חיבור.
2. נותנים למשתמש את הקישור: פותחים בטלפון ולוחצים **Start**. הבוט עונה "🎉 מחוברים!".
3. מבקשים ממנו לשלוח לבוט "תזכיר לי בעוד 2 דקות לשתות מים". אחרי שהתזכורת מגיעה, ההקמה גמורה.

## חוקים
- **לא יוצרים כלום בחשבון שהמשתמש לא אישר בשיחה הזו**: לא עותק ב-GitHub, לא פרויקט ב-Vercel ולא מסד נתונים. חשבון שמחובר במחשב הוא לא אישור.
- **עברית**, חם וישיר. בתחילת כל שלב: שם השלב וכמה זמן הוא לוקח, במשפט אחד. בסוף כל שלב: מה הבא.
- **סודות:**
  - לעולם לא קוראים ולא מדפיסים את `.env.local`. רק הסקריפטים קוראים אותו, והם מדפיסים כן/לא בלבד.
  - לא מבקשים טוקן, מפתח או סיסמה בצ'אט.
  - אם הודבק סוד בצ'אט, אומרים בעדינות להחליף אותו אצל הספק.
- **תקלות:** קודם "נתקעתי" בקובץ השלב המתאים ב-`steps/`. אחר כך `npm run check`, שמראה מה ירוק ומה אדום בבוט החי.
- **לא משנים את `CHECKLIST.md`.** הוא נוצר אוטומטית.

## בסוף
- אומרים ש-`GITHUB_TOKEN` ו-`VERCEL_TOKEN` נחוצים רק להקמה. אפשר למחוק אותם באתרים, או להשאיר עד שיפוגו (אם הוא רוצה שתשנה לו את הבוט בהמשך).
- מציעים את התוספות (`addons/`), במשפט אחד לכל אחת. את "עדכונים אוטומטיים" (`addons/05-updates.md`) מציעים ראשונה: היא דורשת הגדרה אחת ב-GitHub.
- מזכירים שאפשר לבקש ממך שינויים בבוט בכל זמן.
