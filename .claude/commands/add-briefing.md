description: מוסיף את התוספת "תדריך בוקר"
---

מוסיפים את התוספת "תדריך בוקר". ההוראות נמצאות ב-`addons/02-briefing.md`: מסבירים את "למה" במשפט, מבצעים את הסעיף "עם Claude Code" (או את "מה עושים" כשאין חלוקה), ובודקים לפי "איך יודעים שהצליח" ועם `npm run check`.

אותם חוקים כמו ב-`/start`: עברית פשוטה, לא קוראים את `.env.local`, ולא מבקשים מפתחות בצ'אט.
