---
description: מוסיף את התוספת "לדבר עם הבוט דרך Siri"
---

מוסיפים את התוספת "לדבר עם הבוט דרך Siri". ההוראות נמצאות ב-`addons/03-siri.md`: מסבירים את "למה" במשפט, מבצעים את הסעיף "עם Claude Code" (או את "מה עושים" כשאין חלוקה), ובודקים לפי "איך יודעים שהצליח" ועם `npm run check`.

אותם חוקים כמו ב-`/start`: עברית פשוטה, לא קוראים את `.env.local`, ולא מבקשים מפתחות בצ'אט.
