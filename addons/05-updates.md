## בקצרה
בעמוד ההקמה **הפעלת עדכונים אוטומטיים (פעם אחת)** ‹ **Commit changes...** ‹ **Commit changes**. מכאן העדכונים נכנסים לבד, והבוט מודיע לך בטלגרם.

## למה
כשמשהו בערכה משתפר או מתוקן, הבוט שלך מקבל את זה לבד. פעם בשבוע GitHub בודק אם יצאה גרסה חדשה. אם כן, הוא מריץ קודם את כל הבדיקות של הערכה, ורק אם הן עוברות מכניס את הגרסה החדשה. Vercel מעלה את הבוט מחדש, והבוט כותב לך "✅ עודכנתי לגרסה...". התזכורות, הפתקים והרשימות נשארים.

לא חובה. מפעילים רק אחרי שהבוט כבר עובד.

## מה עושים
### בדפדפן
1. בעמוד ההקמה, בתוספת "עדכונים אוטומטיים", לוחצים **הפעלת עדכונים אוטומטיים (פעם אחת)**. נפתח ב-GitHub קובץ חדש, עם השם והתוכן כבר מוכנים. (Vercel לא מעתיק את הקובץ הזה כשהוא יוצר את עותק הקוד, ולכן מוסיפים אותו פעם אחת.) ![](docs/img/update-0.png)
2. לוחצים **Commit changes...**, ובחלון שנפתח שוב **Commit changes**. זה הכול.
3. יש כבר גרסה חדשה? היא נכנסת מיד. אחרי 2–3 דקות הבוט כותב לך בטלגרם "✅ עודכנתי לגרסה...".

### עם Claude Code
1. Claude מוסיף את קובץ העדכון בעצמו. מכאן העדכונים נכנסים לבד, כמו במסלול הדפדפן.
2. **שינית את הבוט עם Claude?** כדי לא למחוק את השינויים שלך, העדכון לא נכנס לבד. כשבעמוד ההקמה כתוב "יש גרסה חדשה", כותבים ל-Claude: "תעדכן את הבוט מהערכה".

## איך יודעים שהצליח
בתוספת "עדכונים אוטומטיים" בעמוד ההקמה כתוב **מעודכן**, עם מספר הגרסה. אחרי כל עדכון הבוט כותב לך בטלגרם.

## נתקעתי
- **כתוב "A file with the same name already exists"**: העדכונים כבר מופעלים. אין מה לעשות.
- **בעמוד ההקמה כתוב "יש גרסה חדשה" כבר כמה ימים**: לוחצים **🔄 לעדכן עכשיו** ‹ **Run workflow** ‹ **Run workflow**. אחרי 2–3 דקות מרעננים את עמוד ההקמה.
- **ליד "עדכון מהערכה" ב-GitHub יש איקס אדום**: הבדיקות של הגרסה החדשה לא עברו, ולכן שום דבר לא השתנה והבוט ממשיך לעבוד בגרסה הקודמת. כותבים לנו, ונתקן.
- **בעמוד ההקמה עדיין כתוב "יש גרסה חדשה", ובריצה ב-GitHub כתוב "שינית את הקוד של הבוט בעצמך"**: העדכון לא נכנס כדי לא למחוק את השינויים שלך. עם Claude Code כותבים: "תעדכן את הבוט מהערכה". במסלול הדפדפן כותבים לנו.
- **הוספת את העדכונים לפני 28.10.2026 (גרסה 1.8.0 ומטה)?** אצלך עדיין עובדת הגרסה הקודמת: מגיעה בקשת עדכון, ולוחצים בה **Merge pull request** ‹ **Confirm merge**. כדי לעבור לעדכון לבד: ב-GitHub פותחים את `.github/workflows/update.yml` ומוחקים אותו (⋯ ‹ **Delete file** ‹ **Commit changes**), ואז מוסיפים אותו מחדש מעמוד ההקמה.
