## בקצרה
1. ב-GitHub, בריפו `telegram-assistant` שלך: **Settings** ‹ **Actions** ‹ **General**. תחת **Workflow permissions** מסמנים **Allow GitHub Actions to create and approve pull requests** ‹ **Save**.
2. בעמוד ההקמה **הוספת קובץ העדכונים ל-GitHub** ‹ **Commit changes...** ‹ **Commit changes**.
3. כשמגיעה בקשת עדכון: **Merge pull request** ‹ **Confirm merge**.

## למה
כשמשהו בערכה משתפר או מתוקן, הבוט שלך יכול לקבל את זה. פעם בשבוע GitHub בודק אם יצאה גרסה חדשה, ואם כן, פותח לך **בקשת עדכון**. שום דבר לא משתנה בבוט עד שאת/ה מאשר/ת בלחיצה.

לא חובה. מפעילים רק אחרי שהבוט כבר עובד. בבקשת עדכון שכתוב בה **This branch has conflicts**, לא מאשרים (ראו "נתקעתי").

## מה עושים
### בדפדפן
**חלק א׳: הגדרה חד-פעמית** (בסדר הזה: קודם ההרשאה, ואחר כך הקובץ)
1. בעמוד ההקמה, בתוספת "עדכונים אוטומטיים", לוחצים **1. ההגדרה ב-GitHub**. (אפשר גם ידנית: ב-GitHub נכנסים לריפו `telegram-assistant` שלך ‹ **Settings** ‹ **Actions** ‹ **General**.)
2. גוללים למטה עד **Workflow permissions**.
3. מסמנים את התיבה **Allow GitHub Actions to create and approve pull requests**. ![](docs/img/update-1.png)
4. לוחצים **Save** שמתחת לתיבה. חוזרים לעמוד ההקמה.
5. לוחצים **2. הוספת קובץ העדכונים ל-GitHub**. נפתח ב-GitHub קובץ חדש, עם השם והתוכן כבר מוכנים. (Vercel לא מעתיק את הקובץ הזה כשהוא יוצר את עותק הקוד, ולכן מוסיפים אותו פעם אחת.) ![](docs/img/update-0.png)
6. לוחצים **Commit changes...**, ובחלון שנפתח שוב **Commit changes**. מיד אחר כך GitHub בודק אם יש גרסה חדשה. אם יש, אחרי דקה מגיעה בקשת עדכון, וממשיכים בחלק ב׳.
   - כתוב "A file with the same name already exists"? הקובץ כבר קיים. ראו "נתקעתי" כדי להריץ את הבדיקה עכשיו.

**חלק ב׳: כשמגיע עדכון**
1. GitHub שולח מייל "🔄 עדכון לבוט מהערכה", ובעמוד ההקמה מופיע **יש גרסה חדשה**. לוחצים על הקישור במייל, או בעמוד ההקמה על **🔄 לבקשת העדכון ב-GitHub**.
2. בעמוד הבקשה גוללים למטה ולוחצים **Merge pull request**. ![](docs/img/update-3.png)
3. לוחצים **Confirm merge**. (אם יש חץ ליד הכפתור, בוחרים **Create a merge commit** ולא Squash.)
4. מחכים דקה או שתיים ומרעננים את עמוד ההקמה. בתחתית כתוב מספר הגרסה החדשה. אם משהו לא ירוק, לוחצים **🚀 הפעילו הכול**. (כשהכול ירוק הכפתור לא מופיע, ואין צורך בו.)

### עם Claude Code
1. Claude מפעיל את ההגדרה החד-פעמית ב-GitHub בעצמו, עם הטוקן שבקובץ `.env.local`.
2. **כשמגיע עדכון:** GitHub שולח מייל "🔄 עדכון לבוט מהערכה". לוחצים על הקישור ‹ **Merge pull request** ‹ **Confirm merge** (אם יש חץ, **Create a merge commit**). אחר כך אומרים ל-Claude "הגיע עדכון", והוא מפעיל את הבוט מחדש.

## איך יודעים שהצליח
בתחתית עמוד ההקמה כתוב מספר הגרסה, ובתוספת "עדכונים אוטומטיים" כתוב **מעודכן**. הבוט ממשיך לענות כרגיל, וכל התזכורות, הפתקים והרשימות נשארים.

## נתקעתי
- **בעמוד ההקמה כתוב "יש גרסה חדשה", אבל הכפתור הכחול מוביל לרשימה ריקה**: עוד לא נפתחה בקשת עדכון. מריצים את הבדיקה עכשיו: ב-GitHub, בריפו שלך ‹ **Actions** ‹ **עדכון מהערכה** ‹ **Run workflow** ‹ **Run workflow**. אחרי דקה הבקשה מופיעה ברשימה.
- **ב-Actions יש איקס אדום ליד "עדכון מהערכה"**: כנראה הקובץ נוסף לפני שסימנת את התיבה בחלק א׳ (או בלי **Save**). מסמנים, שומרים, ומריצים שוב כמו בסעיף הקודם.
- **בבקשת העדכון כתוב "This branch has conflicts"**: שינית בעבר את הקוד של הבוט (למשל עם Claude Code), והעדכון נוגע באותו מקום. במסלול Claude Code כותבים ל-Claude: "תמזג את בקשת העדכון מהערכה". במסלול הדפדפן אפשר לסגור את הבקשה (**Close pull request**) ולהמשיך עם הגרסה הנוכחית.
- **אחרי ה-Merge הבוט לא עונה**: בעמוד ההקמה לוחצים **🚀 הפעילו הכול** ובודקים מה אדום.
