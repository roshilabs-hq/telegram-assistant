# איזה מסלול מתאים לי?

שני המסלולים מגיעים **לאותו בוט בדיוק**. ההבדל הוא רק בדרך.

## שאלה אחת

**יש לך Claude Code שכבר מותקן ועובד ב-VS Code?**
- לא ← **מסלול א׳ (דפדפן)**. לא צריך להתקין כלום, ואפשר לעשות אותו כולו מהטלפון. יש לך Claude באפליקציה או בדפדפן? [אפשר להיעזר בו לאורך הדרך](help-from-claude.md).
- כן ← **מסלול ב׳ (Claude Code)**. Claude מוביל ובודק כל שלב, ואחר כך יכול לשנות את הבוט לפי בקשה.

> ההדרכה לא מסבירה איך מתקינים את Claude Code. אין לך אותו? מסלול א׳ מגיע לאותו בוט בדיוק.

**ובשני המסלולים:** מכיר כבר את GitHub ו-Vercel? במסלול א׳ יש [מדריך מקוצר](quick.md) בעמוד אחד. במסלול ב׳ Claude שואל בהתחלה כמה הסבר אתה רוצה.

## ההשוואה המלאה

| | 🌐 מסלול א׳: מהדפדפן | 💻 מסלול ב׳: עם Claude Code |
|---|---|---|
| מה מתקינים | כלום | כלום. ההדרכה מניחה ש-Claude Code, Git ו-Node.js כבר מותקנים |
| עלות | חינם, מלבד מפתח AI בתשלום לפי שימוש (כמה דולרים בחודש) | מנוי Claude, ומפתח AI בתשלום לפי שימוש |
| איך זה עובד | כפתור ← טופס קצר ← עמוד הקמה עם וי ירוק לכל שלב | Claude מוביל, מסביר, עושה בעצמו ומתקן |
| כשמשהו לא עובד | עמוד ההקמה מראה מה אדום ואיך לתקן | Claude בודק ומתקן איתך |
| שינויים בבוט אחר כך | אפשר לעבור למסלול ב׳ בכל רגע | מבקשים מ-Claude |
| זמן | כחצי שעה | כחצי שעה |

## שני סוגים של AI, ולא כדאי להתבלבל ביניהם
- **🧠 המוח של הבוט** (נדרש בכל הדרכים): מפתח API מאחד משלושת הספקים, Gemini, ChatGPT או Claude. זה חשבון נפרד אצל הספק, בתשלום לפי שימוש. מנוי ChatGPT Plus או Claude Pro **לא** כולל מפתח כזה.
- **🧰 העוזר להקמה** (לא חובה): במסלול א׳, Claude באפליקציה או בדפדפן יכול להסביר ולענות כשנתקעים. במסלול ב׳, Claude Code ב-VS Code מוביל את כל ההקמה. צ'אט רגיל לא יכול להריץ את `/start`, כי אין לו גישה לקבצים במחשב.
