# איזה מסלול מתאים לי?

שני המסלולים מגיעים **לאותו בוט בדיוק**. ההבדל הוא רק בדרך.

## שלוש שאלות

**1. יש לך מחשב (לא רק טלפון)?**
- לא ← **מסלול א׳ (דפדפן)**. אפשר לעשות אותו כולו מהטלפון.
- כן ← ממשיכים לשאלה 2.

**2. יש לך מנוי בתשלום ל-Claude (Pro או Max), ו-Claude Code מותקן?**
- לא ← **מסלול א׳ (דפדפן)**. לא צריך שום מנוי.
- כן ← ממשיכים לשאלה 3.

**3. רוצה לשנות את הבוט בעתיד: להוסיף יכולות, לשנות את האופי שלו, לחבר אותו לדברים אחרים?**
- לא ← **מסלול א׳ (דפדפן)**. הוא הכי מהיר.
- כן ← **מסלול ב׳ (Claude Code)**. Claude יסביר כל שלב, ואחר כך יוכל לשנות את הבוט לפי בקשה.

## ההשוואה המלאה

| | 🌐 מסלול א׳: מהדפדפן | 💻 מסלול ב׳: עם Claude Code |
|---|---|---|
| מה מתקינים | כלום | Node, Git, VS Code, Claude Code |
| עלות | חינם, מלבד מפתח AI בתשלום לפי שימוש (כמה דולרים בחודש) | מנוי Claude, ומפתח AI בתשלום לפי שימוש |
| איך זה עובד | כפתור ← טופס קצר ← עמוד הקמה עם וי ירוק לכל שלב | Claude מוביל, מסביר, עושה בעצמו ומתקן |
| כשמשהו לא עובד | עמוד ההקמה מראה מה אדום ואיך לתקן | Claude בודק ומתקן איתך |
| שינויים בבוט אחר כך | אפשר לעבור למסלול ב׳ בכל רגע | מבקשים מ-Claude |
| זמן | כחצי שעה | כ-40 דקות (כולל התקנות) |

## שני סוגים של AI, ולא כדאי להתבלבל ביניהם
- **🧠 המוח של הבוט** (נדרש בכל הדרכים): מפתח API מאחד משלושת הספקים, Gemini, ChatGPT או Claude. זה חשבון נפרד אצל הספק, בתשלום לפי שימוש. מנוי ChatGPT Plus או Claude Pro **לא** כולל מפתח כזה.
- **🧰 העוזר להקמה** (רק במסלול Claude Code): Claude Code, עם מנוי Claude Pro ומעלה. ההדרכה כתובה ל-**VS Code עם התוסף Claude Code**. צ'אט רגיל ב-claude.ai או באפליקציה בטלפון לא מתאים, כי אין לו גישה לקבצים במחשב. גם ChatGPT ו-Codex לא מתאימים, כי הפקודות (`/start`) הן של Claude Code.
