# איזה מסלול מתאים לי?

שני המסלולים מגיעים **לאותו בוט בדיוק**. ההבדל הוא רק בדרך.

## שלוש שאלות

**1. יש לך מחשב (לא רק טלפון)?**
- לא ← **מסלול א׳ (דפדפן)**. אפשר לעשות אותו כולו מהטלפון.
- כן ← ממשיכים לשאלה 2.

**2. יש לך מנוי בתשלום ל-Claude (Pro או Max), ו-Claude Code מותקן?**
- לא ← **מסלול א׳ (דפדפן)**. לא צריך שום מנוי.
- כן ← ממשיכים לשאלה 3.

**3. רוצה לשנות את הבוט בעתיד: להוסיף יכולות, לשנות את האופי שלו, לחבר אותו לדברים אחרים?**
- לא ← **מסלול א׳ (דפדפן)**. הוא הכי מהיר.
- כן ← **מסלול ב׳ (Claude Code)**. Claude יסביר כל שלב, ואחר כך יוכל לשנות את הבוט לפי בקשה.
