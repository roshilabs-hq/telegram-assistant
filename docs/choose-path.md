# איזו דרך מתאימה לי?

שלוש דרכים, ולכולן אותה תוצאה: **אותו בוט בדיוק, בחשבונות שלך.** בוחרים לפי מה שמתאים לך עכשיו, לא לפי מה ש"צריך".

## מה מתאר אותך?

**🛠️ "אין לי זמן או חשק להתעסק בזה"**
אנחנו מתקינים בשבילך, בחשבונות שלך. אתה רק פותח טלגרם ומחזיק את הכרטיס ליד. [כותבים לנו](support.md#contact).

**🧭 "זו הפעם הראשונה שלי, ואני רוצה להבין מה עושים"**
[צעד אחרי צעד, מהדפדפן](https://roshilabs-hq.github.io/telegram-assistant/): מסך אחד לכל פעולה (או [הכול בעמוד אחד](browser.md)). כל לחיצה מוסברת, עם צילום מסך, ואפשר לעשות הכול מהטלפון. בלי להתקין כלום. יש לך Claude באפליקציה או בדפדפן? [אפשר להיעזר בו לאורך הדרך](help-from-claude.md). כבר מכיר את GitHub ואת Vercel? [המדריך המקוצר](quick.md) הוא עמוד אחד.

**🤖 "אני כבר עובד עם Claude Code"**
[שורה אחת ב-Claude Code](../README.md#claude-code), ו-Claude עושה בעצמו כל מה שאפשר במחשב. אחר כך הוא גם משנה את הבוט לפי בקשה. הדרך הזו מניחה ש-Claude Code כבר מותקן ועובד אצלך. אין לך אותו? אחת משתי הדרכים האחרות.

## ההשוואה המלאה

| | 🧭 צעד אחרי צעד | 🤖 Claude Code |
|---|---|---|
| מה מתקינים | כלום | כלום. ההדרכה מניחה ש-Claude Code, Git ו-Node.js כבר מותקנים |
| עלות | חינם, מלבד מפתח AI בתשלום לפי שימוש (כמה דולרים בחודש) | מנוי Claude, ומפתח AI בתשלום לפי שימוש |
| איך זה עובד | כפתור ← טופס קצר ← עמוד הקמה עם וי ירוק לכל שלב | Claude מוביל, מסביר, עושה בעצמו ומתקן |
| כשמשהו לא עובד | עמוד ההקמה מראה מה אדום ואיך לתקן | Claude בודק ומתקן איתך |
| שינויים בבוט אחר כך | אפשר לעבור ל-Claude Code בכל רגע | מבקשים מ-Claude |
| זמן | כחצי שעה | כחצי שעה |

## שני סוגים של AI, ולא כדאי להתבלבל ביניהם
- **🧠 המוח של הבוט** (נדרש בכל הדרכים): מפתח API של Claude. זה חשבון נפרד אצל הספק, בתשלום לפי שימוש. מנוי ChatGPT Plus או Claude Pro **לא** כולל מפתח כזה.
- **🧰 העוזר להקמה** (לא חובה): בדרך צעד אחרי צעד, Claude באפליקציה או בדפדפן יכול להסביר ולענות כשנתקעים. בדרך של Claude Code, הוא מוביל את כל ההקמה. צ'אט רגיל לא יכול להריץ את `/start`, כי אין לו גישה לקבצים במחשב.

## מה צריך לפני שמתחילים

| | 🧭 צעד אחרי צעד | 🤖 Claude Code |
|---|---|---|
| מכשיר | טלפון או מחשב | מחשב (Windows או Mac) |
| טלגרם | מותקן, עם חשבון | מותקן, עם חשבון |
| מייל | חשבון מייל (Gmail הכי נוח) | חשבון מייל (Gmail הכי נוח) |
| כרטיס אשראי | לספק ה-AI (השלב "מוסיפים לבוט מוח"). את הפרטים מזינים רק באתר של הספק | לספק ה-AI (המנוי ל-Claude כבר קיים אצלך) |
| תוכנות | דפדפן | Claude Code שעובד ב-VS Code, עם Git ו-Node.js |
| חשבונות שנפתחים בדרך | GitHub, Vercel ו-Supabase. מי שכבר יש לו, ההדרכה אומרת בכל שלב מה לעשות | אותו דבר |

> 💡 **לא צריך להתקין סקילים, תוספים או פקודות.** כל הפקודות של הבוט (`/start`, `/add-voice` וכו') מגיעות בתוך הקוד עצמו, ו-Claude Code מכיר אותן מהרגע שהתיקייה נפתחת.
