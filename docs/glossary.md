# מילון מונחים

| מונח | מה זה, במשפט אחד | דימוי |
|---|---|---|
| **בוט** | חשבון בטלגרם שמנוהל על ידי תוכנה ולא על ידי אדם | עובד שעונה לטלפון 24/7 |
| **BotFather** | הבוט הרשמי של טלגרם שבו יוצרים בוטים חדשים | משרד הרישוי של הבוטים |
| **טוקן** | סיסמה ארוכה שבעזרתה הקוד מדבר בשם הבוט | המפתח של הבוט |
| **מפתח API** | סיסמה שמזהה אותך מול שירות (למשל שירות ה-AI), כדי שידע את מי לחייב | כרטיס חבר במועדון |
| **AI / בינה מלאכותית** | השירות שמבין את מה שכותבים לבוט ומחליט מה לעשות | המוח של הבוט |
| **GitHub** | אתר שבו נשמר הקוד של הבוט. העותק שלך שייך לך | הארכיון של הבוט |
| **Vercel** | המחשב באינטרנט שהבוט רץ עליו, דולק כל הזמן | הבית של הבוט |
| **Supabase** | המסד שבו הבוט זוכר תזכורות, פתקים ורשימות | המחברת של הבוט |
| **Deploy (פריסה)** | העלאה של הקוד ל-Vercel כדי שירוץ | להכניס את הבוט לבית |
| **Redeploy** | פריסה מחדש, למשל אחרי ששינית הגדרה ב-Vercel | לכבות ולהדליק |
| **Environment Variables** | ההגדרות הסודיות של הבוט ב-Vercel (טוקן, מפתח, סיסמה) | הכספת של הבוט |
| **עמוד ההקמה (`/setup`)** | עמוד בכתובת של הבוט שמראה מה עובד ומה עוד לא, עם כפתורים לתיקון | לוח הבקרה |
| **SQL** | שפה שבה נותנים פקודות למסד. במדריך לא כותבים אותה: מעתיקים ומדביקים | הוראות הרכבה |
| **Claude Code** | עוזר AI שעובד על הקוד שלך במחשב ומסביר מה הוא עושה | טכנאי שיושב לידך |
| **ריפו (Repository)** | עותק של הקוד של הבוט, שנשמר בחשבון ה-GitHub שלך | תיק בארכיון |
| **Template (תבנית)** | ריפו שמכינים ממנו עותקים חדשים. הערכה היא תבנית | טופס ריק שממלאים |
| **Region (אזור)** | העיר שבה נמצא המחשב של Supabase. Frankfurt היא הקרובה לישראל | כתובת המחסן |
| **Domains (כתובת)** | הכתובת של הבוט באינטרנט, משהו כמו `telegram-assistant-xxxx.vercel.app` | הכתובת של הבית |
| **Google Cloud** | האתר של Google שבו פותחים "אפליקציה" שמחברת את הבוט ליומן ולמייל | משרד הרישוי של Google |
| **Client ID / Client secret** | שם המשתמש והסיסמה של האפליקציה שלך ב-Google | תעודה ומפתח |
| **כתובת החזרה (Redirect URI)** | הכתובת ש-Google שולח אליה אחרי שאישרת את החיבור | הכתובת למשלוח חוזר |
| **Groq** | שירות שהופך הודעה קולית לטקסט, בחינם | מתמלל |
| **`.env.local`** | קובץ במחשב שלך (במסלול Claude Code) שבו מדביקים מפתחות. Claude לא קורא אותו | כספת במגירה |
| **טרמינל** | חלון שבו כותבים פקודות למחשב. במסלול הדפדפן לא צריך אותו | שלט רחוק בטקסט |
| **Node.js, Git, VS Code** | שלוש תוכנות שמסלול Claude Code צריך: להריץ קוד, לשמור גרסאות, ולערוך | ארגז הכלים |
| **קיצורים (Shortcuts)** | אפליקציה באייפון שבונה פעולות אוטומטיות, למשל "היי Siri, עוזר" | מתג חכם |
