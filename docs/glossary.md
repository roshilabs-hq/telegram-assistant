# מילון מונחים

| מונח | מה זה, במשפט אחד | דימוי |
|---|---|---|
| **בוט** | חשבון בטלגרם שמנוהל על ידי תוכנה ולא על ידי אדם | עובד שעונה לטלפון 24/7 |
| **BotFather** | הבוט הרשמי של טלגרם שבו יוצרים בוטים חדשים | משרד הרישוי של הבוטים |
| **טוקן** | סיסמה ארוכה שבעזרתה הקוד מדבר בשם הבוט | המפתח של הבוט |
| **מפתח API** | סיסמה שמזהה אותך מול שירות (למשל שירות ה-AI), כדי שידע את מי לחייב | כרטיס חבר במועדון |
| **AI / בינה מלאכותית** | השירות שמבין את מה שכותבים לבוט ומחליט מה לעשות | המוח של הבוט |
| **GitHub** | אתר שבו נשמר הקוד של הבוט. העותק שלך שייך לך | הארכיון של הבוט |
| **Vercel** | המחשב באינטרנט שהבוט רץ עליו, דולק כל הזמן | הבית של הבוט |
| **Supabase** | המסד שבו הבוט זוכר תזכורות, פתקים ורשימות | המחברת של הבוט |
| **Deploy (פריסה)** | העלאה של הקוד ל-Vercel כדי שירוץ | להכניס את הבוט לבית |
| **Redeploy** | פריסה מחדש, למשל אחרי ששינית הגדרה ב-Vercel | לכבות ולהדליק |
| **Environment Variables** | ההגדרות הסודיות של הבוט ב-Vercel (טוקן, מפתח, סיסמה) | הכספת של הבוט |
| **עמוד ההקמה (`/setup`)** | עמוד בכתובת של הבוט שמראה מה עובד ומה עוד לא, עם כפתורים לתיקון | לוח הבקרה |
| **SQL** | שפה שבה נותנים פקודות למסד. במדריך רק מעתיקים ומדביקים | הוראות הרכבה |
| **Claude Code** | עוזר AI שעובד על הקוד שלך במחשב ומסביר מה הוא עושה | טכנאי שיושב לידך |
