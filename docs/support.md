# תמיכה

הערכה חינמית, והבוט רץ בחשבונות שלך. הנה מה אנחנו עושים בשבילך, ומה לא.

## מה כלול
- **תיקון ההדרכה.** נתקעת? זה באג אצלנו, לא אצלך. מתקנים את השלב כדי שהבא אחריך לא ייתקע.
- **תיקון באגים בקוד ועדכוני אבטחה.** מגיעים אליך בבקשת העדכון השבועית ב-GitHub ([איך מאשרים עדכון](browser.md#step-updates)).

## מה לא כלול
- התאמות אישיות לבוט (יכולות חדשות, אופי אחר, חיבור לשירותים נוספים). במסלול Claude Code אפשר לבקש את זה מ-Claude בעצמך.
- טיפול בחשבונות שלך (Google, Vercel, Supabase, ספק ה-AI), כולל חיובים וסיסמאות. לא נבקש ממך אף פעם מפתח, טוקן או סיסמה.
